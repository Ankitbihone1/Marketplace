\# Marketplace



A marketplace application for construction and home-building products where multiple local sellers can offer the same product at different prices, stock levels, and minimum order quantities.



\## Tech Stack



\### Backend

\- Java 17

\- Spring Boot

\- Spring Data JPA

\- PostgreSQL

\- Flyway

\- Maven



\### Frontend

\- React

\- Vite

\- JavaScript

\- Tailwind CSS
